<Shot src="agents" alt="The Agents page with three agents: Dev, Sales and Support" />

You build one agent per job: one for support, one for sales, one for engineering questions. Each agent lives in its
own sandbox on your server, answers in its own Slack app or WhatsApp number, and reads only the data you hand it.
