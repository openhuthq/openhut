---
title: Setup
description: Copy one prompt into Claude Code, Cursor or Codex. It sets OpenHut up with you.
icon: growth
---

<Shot src="agents" alt="The Agents page with the Copy prompt button" />

<Steps>
<Step>

### Copy the prompt

**Agents**, then **Copy prompt**. Paste it into your assistant.

</Step>
<Step>

### Sign in

Your assistant opens OpenHut in the browser. Approve it. There's no token to copy.

</Step>
<Step>

### Ask

```txt
Make a Support agent that answers in #support and can read the Orders DB.
```

</Step>
</Steps>

In Claude Code you can also add it by hand:

```sh
claude mcp add --transport http openhut https://YOUR-SERVER/mcp
```
