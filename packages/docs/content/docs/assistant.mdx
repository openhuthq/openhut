Everything the dashboard does, your assistant can do too: create agents, write their instructions, hand them
connections and invite people.

<Steps>
<Step>

### Copy the prompt

Open **Agents** and press **Copy prompt**.

</Step>
<Step>

### Paste it into your assistant

It adds Fast Monkey as an MCP server. In Claude Code that's one command:

```sh
claude mcp add --transport http fastmonkey https://YOUR-SERVER/mcp
```

</Step>
<Step>

### Sign in

Your assistant opens Fast Monkey in the browser. Sign in and approve it. There's no token to copy.

</Step>
<Step>

### Ask for what you want

```txt title="Say to your agent"
Make a Support agent that answers in #support and can read the Orders DB.
```

</Step>
</Steps>

Connected assistants are listed under **Admin**. An assistant can do what you can do, and no more.
