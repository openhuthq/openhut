Each conversation an agent has is a **thread**, and every thread shows up in the web app, whether it started there, in Discord, from a webhook or from a routine. Each thread lives in one place, its channel.

## Find a thread

Open an agent and its threads fill the panel on the right, under **Threads**. Each one is one line: a status icon, the title, an icon for where it came from (Web, Discord, a webhook or a routine; hover it for the channel or name) and when it last moved. The thread you have open is highlighted, and the chat header shows its title.

- The agent's **main thread** comes first, then the newest. **+ New** starts an empty web thread, named after your first message. **View all** opens a search over every thread, with **New thread** (⌘J) at the top.
- The status icon says where each thread stands: an orange dot when it's **waiting on you**, a spinning arc while the agent works, a dashed circle when there's nothing to do. The sidebar lists only agents, each with its newest message and when it came. An orange dot means a thread is waiting on you; a small spinner on the face means the agent is at work. A webhook setup thread stops waiting once the webhook gets its first call, or when you press **Done** on its card.
- Hover a thread and press **Archive** to take it off the list. The agent's main chat can't be archived.

## Where you reply

A thread stays where it started. A web thread continues in the web app. A Discord thread continues in Discord, and the web app shows it as it happens but has no message box: **Open in Discord ↗** takes you there. A webhook or routine that posts in a Discord channel makes a Discord thread too.

Every message is saved in OpenHut before it goes anywhere. If Discord refuses a reply, the reply still stays in the thread.

## See who's here

A thread is live for everyone who has it open.

- The header shows the faces of the people in the thread and **N here**. Click it to see who is **Viewing** or **Typing**, and whether the agent is **Replying**, **Working** or **Idle**.
- **Sara is typing** shows above the message box while someone else types. In the Threads list a thread shows the working icon while the agent replies.
- The agent's reply streams to everyone as it writes, with what it is doing right now, **Answering Mo and Ahmed** and **Live · 3 watching**. That includes replies to webhooks and routines.
- **Seen by** under your last message shows who has the thread open now.

## Notify me

**Setup › General › Notify me** on the agent sets where the agent tells you about things it finds on its own:

- **Usually in**: one of the agent's channels, or **Only here in the web app**.
- **Rules**: plain words the agent follows, like "Post incidents and new Linear issues in #on-call. Everything else stays here."

When the agent tells you somewhere else, the thread shows a quiet line: **Notified #on-call**.
