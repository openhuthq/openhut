<Steps>
<Step>

### Name it

**+** at the top of the sidebar. Pick a face, name it after its job, like Support, Sales or Ops, then **Create**. Double-click the name to change it later.

</Step>
<Step>

### Tell it its job

Write **What it does** the way you'd brief a new teammate. Two sentences are enough.

</Step>
<Step>

### Give it a channel and data

Under **Talk to it on**, **Set up** [Slack](/slack), [Discord](/discord), [WhatsApp](/whatsapp) or [Telegram](/telegram). Under **Can use**, **Add** the [connections](/data) it needs. Or just chat with it in the app.

</Step>
<Step>

### Pick where it runs

**Model** picks what it thinks with: a Claude or [ChatGPT](/codex) model from your [subscription](/claude), or one from an [API key](/api-keys). **Runs on** shows its computer: Cloud or a [computer you add](/computers); **Move to** moves it.

</Step>
</Steps>

The buttons next to its name stop and start it, clear the chat and delete it. Stopping keeps what it learned; clearing the chat keeps its memory.

## Run code and Browser

Each agent can run code. Switch **Run code** off for an agent that shouldn't.

An agent can also use a real web browser. **Browser** is off until you switch it on; the agent restarts once. The browser runs inside the agent's sealed box and reaches the public web over HTTPS only, and the agent can use up to 4 GB of memory instead of 1 GB while Browser is on.

**Open**, next to Browser, shows what its browser has open, live, with each step it takes. Press **Take over** to click and type yourself, for example to log in to a site or get past a check; the agent can't act until you hand back, or after 2 minutes without input.

Logins stay in the agent's browser between conversations. The agent can read its own browser, so log it in with an account made for it, not your personal one. A web page can carry text written to mislead an agent, so switch Browser on only for agents that need it.
