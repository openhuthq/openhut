## Its own sandbox

Each agent runs in its own gVisor container with a read-only system and its own network. It can't reach another agent, your server or your LAN.

## A firewall

Agents can make HTTPS calls out, and nothing else. Private ranges and the cloud metadata address are blocked. If the firewall can't be applied, every agent stops.

## OpenHut holds the keys

Agents reach your data only through OpenHut's gateway. It keeps every password encrypted, checks each call against what you allowed, and logs it.

## What it doesn't cover

A tricked agent can still leak what it holds itself: its Slack, WhatsApp or Telegram credentials, its memories and the shared Claude token.
