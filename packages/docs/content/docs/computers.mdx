**Settings › Computers › Add a computer** gives you a command with a code in it. Run it on an always-on Linux computer, or let the app run it for you over Tailscale. Either way the computer asks to join your account, and you **Approve** it.

## With a command

The app shows a command with a code in it. The code works once, for 10 minutes. Run it on the computer:

```sh
curl -fsSL openhut.dev | sh -s -- join '<code>'
```

It installs OpenHut there and asks to join, which takes a few minutes. The code stands in for a Google sign-in, so the computer never needs your Google account. Back in the app, a notice says it wants to join; **Approve** it, here or in **Settings › Computers**. Nothing needs a public address or an open port: your devices reach it through our relay, end-to-end encrypted, so we can't read it.

## Over Tailscale

If the computer is on your [tailnet](https://tailscale.com/download), the app can run the install for you, so you don't paste anything. Tailscale is only used for that first install: afterwards the computer talks to your devices through the relay, like any other. Your Mac and the computer both need to be on your tailnet. Turn on Tailscale SSH on the computer once:

```sh
sudo tailscale set --ssh
```

Pick **Tailscale**, then the computer. The app runs the same install with a join code over Tailscale SSH, and the computer asks to join like any other; **Approve** it. If Tailscale asks you to approve something, a link shows up; open it and approve.

## Put agents on it

Open an agent, then **Runs on › Move to** the computer. Its settings, chats, memory, skills, routines, connections and channels are in your account, so they come along. Its own files, browser logins and WhatsApp link stay on the old computer: link WhatsApp again after a move. An agent runs only on its owner's computers.

## One account, many computers

Every computer runs its own agents and keeps working while your Mac is off. The app shows them all in one place: the sidebar names each agent's computer, and an agent on an offline computer is greyed out.

Connections and API keys belong to your account, not to a computer, so every computer of yours can use them. Your [Claude plan](/claude) works on all of them too.

To remove a computer, **⋯ › Remove**. Its agents stop and it's cut off from your account; nothing is deleted there. To wipe it, see [Uninstall](/uninstall).

## What the computer needs

Linux (Debian, Ubuntu or Alpine, x86_64 or arm64), always on, with Docker. The install adds Docker if it's missing and leaves the rest of the machine alone.

OpenHut arrives as one prebuilt image, `ghcr.io/openhuthq/runtime`, that already holds everything a computer needs: the OpenHut server, the agent runtime, gVisor, Claude Code and the browser. The installer pins the exact image of its release by digest, so Docker refuses anything else. It runs as the container `openhut`, with each agent in its own gVisor sandbox inside it, and keeps its data in two Docker volumes: `openhut-data` (agents, settings, logs) and `openhut` (the agents' sandboxes). A small container, `openhut-updater`, does the updates you start from the app.

Plan memory for the busiest moment: every running agent can use up to 1 GB, or 4 GB with Browser on.

| Computer | CPU | Memory | Disk |
| --- | --- | --- | --- |
| 2 agents, no browser | 2 vCPU | 4 GB | 20 GB |
| 5 agents, 2 of them browse | 4 vCPU | 8 GB | 30 GB |
| 10 agents, 4 of them browse | 8 vCPU | 16 GB | 40 GB |

- **Memory:** 1 GB for OpenHut and the system, plus 1 GB for each running agent, and 2 GB for each one that browses.
- **CPU:** one core for OpenHut, plus one for each agent working at the same moment.
- **Disk:** 10 GB for OpenHut (a 1.5 GB download that unpacks to about 6 GB), plus about 1 GB per agent.

## Troubleshooting

- **The code expired.** Make a new one and run the new command.
- **The Tailscale list is empty or says Tailscale is off.** Install Tailscale on your Mac, open it and sign in, then **Check again**.
- **"Tailscale SSH is off".** Run `sudo tailscale set --ssh` on that computer, then **Check again**.
- **A computer shows Offline.** Check that it's on and connected to the internet. Its agents keep running there; the app catches up when it's back.
- **A computer added before the OpenHut image.** It updates as before, but to move it to the image, run the install command on that computer once: `curl -fsSL openhut.dev | sh`. Its agents, settings and data come along, and the old container is kept, stopped, as `openhut-legacy` until you remove it (`docker rm openhut-legacy`).
- **A computer added over Tailscale before 0.6.2.** It talked to your Mac over your tailnet, which OpenHut no longer does. Remove it and add it again; its agents' settings and chats come back from your account.
