**Settings › Your devices › Add a computer** gives you two ways to reach it:

- **Tailscale.** Use the Tailscale you already have. Your Mac talks to the computer straight over your tailnet. No OpenHut account, and nothing goes through OpenHut.
- **OpenHut Relay.** The easiest way, no Tailscale needed. Traffic goes through our relay, encrypted so we can't read it. Needs [OpenHut Cloud](/cloud).

Each computer in the list says which one it uses.

## Tailscale

Your Mac and the computer both need to be on your [tailnet](https://tailscale.com/download). Turn on Tailscale SSH on the computer once:

```sh
sudo tailscale set --ssh
```

Pick **Tailscale**, then the computer. The app installs OpenHut over Tailscale SSH and pairs with it over the same connection, so there are no numbers to check. If Tailscale asks you to approve something, a link shows up; open it and approve.

The install shares one port, 8788, with your tailnet only (`tailscale serve --bg --tcp 8788`). It adds that entry and leaves your other `tailscale serve` settings alone. Only your Mac's key, signed into the computer during pairing, gets past that port. Your tailnet's access rules need to let your Mac reach it.

A computer added this way never connects to the relay. To move one you added through the relay, pick it in the Tailscale list and **Switch**. It keeps its agents and data.

## OpenHut Relay

Pick **OpenHut Relay**. The app shows a command with a code in it. Run it on an always-on Linux computer:

```sh
curl -fsSL openhut.dev | sh -s -- join '<code>'
```

It installs OpenHut there and asks to join, which takes a few minutes. Back in the app, check that the computer shows the same numbers, then **Allow** it. Nothing needs a public address or an open port.

## Put agents on it

Open an agent, then **Runs on › Move to** the computer. Its memory, skills, chats and channels go with it.

## Each computer is its own

Every computer runs its own agents, connections and keys, and keeps working while your Mac is off. The app shows them all in one place: the sidebar names each agent's computer, and an agent on an offline computer is greyed out.

A connection lives on the computers you put it on. **Connect apps** lists it once, with a chip per computer. If an agent needs one that isn't on its computer yet, **Add to** that computer under **Can use**. Your [Claude plan](/claude) is pushed to every computer.

To remove a computer, **⋯ › Remove**. Its agents stop and their keys stay on it; nothing is deleted there. To wipe it, see [Uninstall](/uninstall).

## What still talks to openhut.dev

With only Tailscale computers: downloading OpenHut and its updates (they install only when you click **Update**), and anonymous usage data, which you can turn off in **Settings › General**. Your Mac's own runtime connects to the relay only while a phone or an invitation needs it.

Phones always reach your computers through the relay, so a Tailscale-only computer shows as offline on a phone.

## What the computer needs

Linux (Debian, Ubuntu or Alpine, x86_64 or arm64), always on. OpenHut runs in one Docker container named `openhut`, with each agent in a gVisor sandbox inside it. The install adds Docker if it's missing and leaves the rest of the machine alone.

Plan memory for the busiest moment: every running agent can use up to 1 GB, or 4 GB with Browser on.

| Computer | CPU | Memory | Disk |
| --- | --- | --- | --- |
| 2 agents, no browser | 2 vCPU | 4 GB | 20 GB |
| 5 agents, 2 of them browse | 4 vCPU | 8 GB | 30 GB |
| 10 agents, 4 of them browse | 8 vCPU | 16 GB | 40 GB |

- **Memory:** 1 GB for OpenHut and the system, plus 1 GB for each running agent, and 2 GB for each one that browses.
- **CPU:** one core for OpenHut, plus one for each agent working at the same moment.
- **Disk:** 10 GB for OpenHut and the agent image, plus about 1 GB per agent.

## Troubleshooting

- **The code expired.** Make a new one and run the new command.
- **The Tailscale list is empty or says Tailscale is off.** Install Tailscale on your Mac, open it and sign in, then **Check again**.
- **"Tailscale SSH is off".** Run `sudo tailscale set --ssh` on that computer, then **Check again**.
- **"Can't reach port 8788".** Your tailnet's access rules block your Mac from that port. Allow it, then add the computer again.
- **"Port 8788 is taken".** Something else on the computer uses it. Free it, then add the computer again.
- **"Offline · Tailscale is off on this Mac".** Open Tailscale on your Mac.
- **A Tailscale computer shows Offline for good.** Its Tailscale key may have expired. Turn off key expiry for always-on servers in the Tailscale admin console.
- **A computer shows Offline.** Check that it's on and connected to the internet. Its agents keep running there; the app catches up when it's back.
- **Remove the port from your tailnet.** On the computer: `sudo tailscale serve --tcp=8788 off`.
