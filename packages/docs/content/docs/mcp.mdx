<Steps>
<Step>

### Copy the command

**Settings › MCP**. There's one command per computer: `openhut` for this Mac, and `openhut-<name>` for each computer you added.

</Step>
<Step>

### Run it once

Paste it in your terminal. It adds OpenHut to Claude Code. There's no token and no sign-in: it runs the app's local bridge.

</Step>
<Step>

### Ask

```txt
Make a Support agent that answers in #support and can read the Orders DB.
```

</Step>
</Steps>

## Other MCP apps

**Other apps › Copy path** copies the bridge. Add it to your app as a stdio server. For another computer, add `--computer <id>` after the path, as in its Claude Code command.

The commands for added computers go through this Mac, so they work while OpenHut is open here. Their keys never leave the app.
