<Steps>
<Step>

### Copy the command

**Settings › MCP**. Copy the Claude Code or Codex command, or click **Add to Cursor**. There's one MCP, `openhut`, for this computer and every computer you added.

</Step>
<Step>

### Run it once

Paste it in your terminal. There's no token and no sign-in: it runs the app's local bridge.

</Step>
<Step>

### Ask

```txt
Make a Support agent on hermes-agents that answers in #support and can read the Orders DB.
```

</Step>
</Steps>

## Every computer

Each tool takes an optional `computer`: a name or id from `list_computers`. Leave it out and the tool runs on this Mac. Calls to other computers go through this Mac, so they work while OpenHut is open here. Their keys never leave the app.
