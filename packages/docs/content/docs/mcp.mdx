title: MCP
description: Let Claude Code or any MCP app make agents and grant access for you.
icon: growth
---

<Steps>
<Step>

### Copy the command

**Settings › MCP**. Copy the Claude Code or Codex command, or click **Add to Cursor**. There's one MCP, `openhut`, for your whole account.

</Step>
<Step>

### Run it once

Paste it in your terminal. There's no token to paste: it runs the app's local bridge.

</Step>
<Step>

### Ask

```txt
Make a Support agent on hermes-agents that answers in #support and can read the Orders DB.
```

</Step>
</Steps>

## Every computer

Your agents live in your account, not on one computer, so the MCP sees and changes all of them, wherever each one runs. It goes through OpenHut on this computer, so it works while the app is open here. Your keys never leave the app.
