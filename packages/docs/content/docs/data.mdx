<Shot src="connections" alt="The Connections page with two Postgres databases" />

<Steps>
<Step>

### Add the database

**Connections**, then **Postgres**. Paste the connection string of a read-only login.

</Step>
<Step>

### Hand it to an agent

Tick it under **Connections** on the agent's page.

</Step>
<Step>

### See what it ran

Open the connection. Every call is listed, refused ones too.

</Step>
</Steps>

Each query is one `SELECT`, at most 15 seconds and 1000 rows. Turn on **Everyone on the team** to share a connection.
