---
title: API keys
description: Run agents on OpenRouter, OpenAI or xAI models with your own key.
icon: support
---

<Steps>
<Step>

### Get a key

- **OpenRouter:** [openrouter.ai/keys](https://openrouter.ai/keys). One key for hundreds of models.
- **OpenAI:** [platform.openai.com/api-keys](https://platform.openai.com/api-keys).
- **xAI:** [console.x.ai](https://console.x.ai).

</Step>
<Step>

### Paste it

**Settings › Models**, then **Add key** next to the provider under **API keys**. Paste the key and, under **Put it on**, pick the [computers](/computers) it goes on. **Test and connect** checks it and fetches the models you can use.

</Step>
<Step>

### Pick a model

On the agent, **Model** lists them. Open the provider in **Settings › Models** to switch models off; switched-off models stay out of the pickers.

</Step>
</Steps>

The key is sealed on each computer you put it on. You won't see it again, and agents never see it.

## Helper models

Besides its **Model**, each agent has **Helper models** for summarising, naming chats and learning from them. They start on automatic. Change them on the agent's panel.
