<Steps>
<Step>

### Sign in

Open [app.openhut.dev](https://app.openhut.dev) and press **Continue with Google**. OpenHut runs in your browser, on any computer or phone. See [OpenHut Cloud](/cloud).

</Step>
<Step>

### Pick where your agents live

- **Cloud**: a computer we run for you, paid from your credits. It's ready in a minute or two.
- **Your own server**: any Linux server with Docker. OpenHut shows one command to run there. See [Computers](/computers).

Add more later in **Settings › Computers**.

</Step>
<Step>

### Make your first agent

OpenHut opens on **Make your first agent**. Pick a face and a name, then **Create**. Tell it its job under **What it does**. See [Multiple agents](/agents).

</Step>
<Step>

### Add your Claude plan

**Settings › Models**, then **Sign in** next to Claude subscription. See [Claude plan](/claude).

</Step>
</Steps>

On Cloud and on a [computer you add](/computers), each agent runs in its own process, apart from the others.
