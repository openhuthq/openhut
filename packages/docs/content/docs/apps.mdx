**Settings › Apps**, then **Connect** next to the app. A short guide opens with the steps. An agent that needs an app asks for it in chat, with a button that opens the same guide.

On the agent, **Add** it under **Can use**. Or pick the agents under **Can use** on the app.

</Step>

## What you can connect

Each is an official MCP server, run with your own credentials:

- **GitHub:** a GitHub App of your own. You approve it twice; agents commit as its bot.
- **Google:** Gmail (drafts only, no sending), Drive, Docs, Sheets, Slides, Calendar, Chat and Contacts. Needs a Google OAuth client, set once by an admin (below).
- **Linear** and **PostHog:** sign in.
- **Convex:** a deploy key.
- **Excalidraw:** no account. Agents draw a diagram and send a link to it; anyone with the link can open it.
- **Postgres:** read-only. Paste a connection string, or host, database, user and password. **Copy SQL** gives you the statements for a read-only role.
- **Custom MCP:** any MCP server by URL, with a header (like `Authorization`) or OAuth.

## Google OAuth client

In Google Cloud Console, create an OAuth client of type **Web application** and add the redirect URL OpenHut shows. Paste its client ID and secret when you first connect Google, or in **Settings › Admin › Sign in with Google**. One client serves Google sign-in and the Google apps.

Keys stay on your main install, sealed. Agents call apps through OpenHut and never see them. What each agent may do in an app on its own, and what it asks you first, is under [Permissions](/permissions).
