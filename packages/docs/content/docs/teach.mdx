Tell it what to do differently, in the same thread:

```txt
Next time an order is late, tell the customer too.
```

The agent saves that as a skill and follows it from then on. Skills survive restarts and upgrades.

**What it does** is the job, and you write it. **Skills** are what it picks up on the job, and it writes them.

## Skills

**Setup › Skills** on the agent lists what it learned. Open one to read it, edit it or delete it; a deleted skill is forgotten for good. **Built in** shows the skills that come with OpenHut and its connections: the agent reads them but can't change them.

## Memory

**Setup › Memory** on the agent holds what it keeps about **People** and its own **Notes**. Add an entry to tell it something up front, or fix or remove one it got wrong.

Clearing the chat keeps both. Moving the agent to another [computer](/computers) takes both with it.
