## Agent

An agent does one job for your team, like answering support questions or posting the weekly sales report. It has a
name, instructions you write in plain words, and its own sandbox on your server. [Create one](/agents).

## Channel

A channel is where people talk to an agent. Each agent gets its own [Slack app](/slack) and its own
[WhatsApp number](/whatsapp), and you choose who may message it.

## Connection

A connection is team data an agent may read. Today that's [Postgres](/data), read-only. Fast Monkey keeps the
password, so the agent never sees it, and every query lands in a log.

## Skill

A skill is something an agent has learned to do. When someone corrects an agent in chat, it writes the lesson down
and follows it next time. You never rewrite its instructions for that. [Teach it](/teach).

## Who does what

<Shot src="people" alt="The People page with an owner, an admin and a member" />

The **owner** installed Fast Monkey. **Admins** invite people and manage the server with the owner. **Members** build
and run their own agents.
