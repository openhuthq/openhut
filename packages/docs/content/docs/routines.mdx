Ask an agent to keep at something, or just mention something that needs a follow-up:

```txt
Chase Acme on invoice 4471 until it's paid.
```

The agent sets up a **routine**: once ("Friday at 9"), repeating ("weekdays at 10") or until something happens ("until it's paid"). Each time it runs, the agent picks it up in the same chat it was asked in, with that chat's history, and tells you only when there's something to say. When it's done for good, it says so and clears the routine. Times are in your team's time zone, which OpenHut takes from your browser, and the agent tells you which one.

## See them

**Setup › Routines** (the gear at the top of the agent's chat) lists what's coming up. Open one to see the agent's plan in its own words, when it runs next, where it reports and what it said last time.

To change the plan, tell the agent. It changes the routine in place, so it keeps where it posts and your **No end date**. Two things you can set yourself:

- **Posts in** moves the routine to another place the agent already posts: the OpenHut app or any chat on its channels.
- **No end date** keeps a repeating routine going past its 90 days until you or the agent stop it.

**Run now** runs it right away, where it posts, so you can see what it does without waiting for its time. Its next run stays where it was. It's off while a run is going.

**Stop** ends one for good.

A routine that can't run three times in a row (the agent was stopped or didn't answer) stops trying and shows in red, so nothing fails quietly. **Clear** takes it off the list.

## Limits

- Up to 20 routines and 100 runs a day per agent, at most every 15 minutes, for up to 90 days unless you turn on **No end date**.
- A routine reports only to a chat the agent is in. On a WhatsApp or Telegram number anyone can message, only to yours.
- A routine can't set up another routine. An agent can run one of its own right away to check it after setting it up.
- Routines run while the agent is running. One that comes due while it's stopped waits and runs once when it starts again.
- Every call a routine makes goes through the same [connections and grants](/data) as a chat.
