<Steps>
<Step>

### Sign in

**Settings › Models**, then **Sign in** next to Claude subscription. The first time, OpenHut downloads Claude Code (about 100 MB), which your agents use to reach Claude. Then claude.ai opens in your browser. Press **Authorize**.

</Step>
<Step>

### Paste the code

claude.ai shows a code. Paste it in the app. Every agent uses it from then on.

</Step>
</Steps>

You sign in once, and every [computer](/computers) of yours uses it. The row shows how much of the 5-hour limit is used, and **Claude this week** shows which agents used it.

Use a Pro or Max plan set aside for agents. Their work counts against its limits. For ChatGPT, see [ChatGPT plan](/codex); for OpenRouter, OpenAI or xAI, see [API keys](/api-keys).
