<Steps>
<Step>

### Sign in

**Settings › Models**, then **Sign in** next to Claude subscription. claude.ai opens in your browser. Press **Authorize**.

</Step>
<Step>

### Paste the code

claude.ai shows a code. Paste it in the app. Every agent uses it from then on.

</Step>
</Steps>

You sign in once. The app puts it on every [computer](/computers) you add, too. The row shows how much of the 5-hour limit is used, and **Claude this week** shows which agents used it.

Use a Pro or Max plan set aside for agents. Their work counts against its limits. For ChatGPT, see [Codex plan](/codex); for OpenRouter, OpenAI or xAI, see [API keys](/api-keys).
