---
title: Your Claude plan
description: Agents run on the Claude subscription you already pay for. One token covers every agent.
icon: logo:claude
---

<Shot src="claude-seat" alt="The Admin page with the Claude seat field open, waiting for a token" />

<Steps>
<Step>

### Make a token

On any computer signed in to the Claude seat you want agents to use, run:

```sh
claude setup-token
```

</Step>
<Step>

### Paste it

Open **Admin**, press **Set up** next to **Claude seat**, paste the token and press **Save**. Fast Monkey stores it on
your server and restarts every agent with it.

</Step>
</Steps>

Use a seat you set aside for agents, not your own. Everything the agents do counts against that seat's limits.
