---
title: Claude plan
description: Agents run on the Claude Pro or Max subscription you already pay for. One per install.
icon: logo:claude
---

<Steps>
<Step>

### Sign in

**Settings › Models**, then **Sign in** next to Claude, then **Sign in with Claude**. claude.ai opens in a new tab. Press **Authorize**, then **Copy code**.

</Step>
<Step>

### Paste the code

Paste it in OpenHut and press **Connect**. Every agent on every computer can use it from then on.

</Step>
</Steps>

An install has one Claude subscription, shared by all its agents. Use a plan set aside for agents: their work counts against its limits. **Claude this week** in Settings › Models shows each agent's share and how much of the 5-hour and weekly limits is used.

Only owners and admins can connect or disconnect it.
