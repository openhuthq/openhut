<Step>

### Make a token

On a computer signed in to the seat:

```sh
claude setup-token
```

</Step>
<Step>

### Paste it

**Admin**, **Claude seat**, **Save**. Every agent restarts with it.

</Step>
</Steps>

Use a seat set aside for agents. Their work counts against its limits.
