---
title: Admin
description: Settings for the whole install. Owner and admins only.
icon: finance
---

**Settings › Admin** has:

- **Address:** the HTTPS address of your install, like `https://openhut.example.com`. Point its DNS at the server first; OpenHut gets the certificate itself on ports 80 and 443 and shows until when it's valid.
- **Sign in with Google:** paste your own Google OAuth client so your team can sign in with Google. Only people in your team can. The same client serves the [Google apps](/apps).
- **Email:** an SMTP server (host, port, username, password, from address) for password reset emails. **Send test email** checks it.
- **Share usage data:** sends a daily count to openhut.dev. See [Data](/data).
