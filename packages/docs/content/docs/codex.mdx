---
title: ChatGPT plan
description: Agents run on the ChatGPT Plus or Pro plan you already pay for.
icon: logo:codex
---

<Steps>
<Step>

### Sign in

**Settings › Models**, then **Sign in** next to ChatGPT. OpenHut shows a code and opens a page.

</Step>
<Step>

### Enter the code

Sign in to ChatGPT on that page and enter the code. OpenHut finishes on its own.

</Step>
<Step>

### Pick it on an agent

On the agent, **Model** lists the ChatGPT models next to the others.

</Step>
</Steps>

Use a plan set aside for agents: their work counts against its limits.
