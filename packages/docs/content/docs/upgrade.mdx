---
title: Upgrade
description: The app updates itself. Computers you added update with one click.
icon: support
---

**Settings › Updates** shows the version you run, with **Check for updates**. The app checks every few hours and downloads a new version in the background. A card in the sidebar shows the download, then **Restart to update**; the same page shows the same button. Your agents keep working; this Mac updates with the app.

Turn on **Try new features early** on the same page to get beta versions before everyone else. Turn it off and you stay on the beta you have until a newer stable version comes out; the app never goes back to an older version. Computers you added always get stable versions.

Each computer you added is listed in **Settings › Computers**. When one is behind, press **Update** next to it, or **⋯ › Update**. Nothing on those computers updates on its own.

The computer downloads the new OpenHut image, checks it's the one the release names, and restarts on it, usually in under a minute. Agents, connections, memory and chats stay. Each running agent restarts once. If the new version doesn't start, the computer goes back to the one it had, data included, and the row says why.
