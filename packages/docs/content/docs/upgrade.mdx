---
title: Upgrade
description: Click Update now in Admin, or run the install command again. Either keeps everything.
icon: support
---

**Admin** shows the build you run and whether a newer one is out. When there is, an owner or admin clicks **Update now**. Fast Monkey downloads the release, restarts, and the page reloads on the new build. Nothing updates on its own.

Or run the install command again on the server:

```sh
curl -fsSL https://fastmonkey.dev | sh
```

People, agents, connections and skills stay. Each running agent restarts once.
