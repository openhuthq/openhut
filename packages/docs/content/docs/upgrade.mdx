---
title: Upgrade
description: Click Update now in Admin, or run the install command again. Either keeps everything.
icon: support
---

**Admin** shows the version you run, like `0.1.40`, and whether a newer one is out. When there is, an owner or admin clicks **Update now**. The row says **Updating** while OpenHut downloads the release and restarts, also after a refresh, and the page reloads on the new version. If the new release doesn't come up, the previous one is put back. Nothing updates on its own.

Or run the install command again on the server:

```sh
curl -fsSL https://openhut.dev | sh
```

People, agents, connections and skills stay. Each running agent restarts once.
