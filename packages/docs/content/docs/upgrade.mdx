---
title: Upgrade
description: The app updates itself. Computers you added update with one click.
icon: support
---

**Settings › General** shows the version you run, with **Check now**. The app checks every few hours and downloads a new version in the background. A card in the sidebar shows the download, then **Restart to update**. Your agents keep working; this Mac updates with the app.

Each computer you added is listed in **Settings › Your devices**. When one is behind, press **Update** next to it, or **⋯ › Update**. Nothing on those computers updates on its own.

Agents, connections, memory and chats stay. Each running agent restarts once.
