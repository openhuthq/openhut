---
title: Upgrade
description: The app updates itself. Computers you added update with one click.
icon: support
---

**Settings › Updates** shows the version you run, with **Check for updates**. The app checks every few hours and downloads a new version in the background. A card in the sidebar and on that page shows the download, then **Restart to update**. Your agents keep working; this Mac updates with the app.

Pick **Try new features first** under **Channel** on the same page to get beta versions early. Pick **Stable releases** again and you stay on the beta you have until a newer stable version comes out; the app never goes back to an older version. Computers you added always get stable versions.

Each computer you added is listed in **Settings › Your devices**. When one is behind, press **Update** next to it, or **⋯ › Update**. Nothing on those computers updates on its own.

Agents, connections, memory and chats stay. Each running agent restarts once.
