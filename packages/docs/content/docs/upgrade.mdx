---
title: Upgrade
description: The app updates itself. Computers you added update with one click.
icon: support
---

**Settings › Computers** shows the version you run. The app checks every few hours, downloads a new version in the background and installs it when it restarts. **Restart to update** does it now. This Mac updates with the app.

Each computer you added is listed under it. When one is behind, press **Update** next to it, or **⋯ › Update** in **Settings › Computers**. Nothing on those computers updates on its own.

Agents, connections, memory and chats stay. Each running agent restarts once.
