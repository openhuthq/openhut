## A computer you added

In the app, **Settings › Computers**, then **⋯ › Remove**. Its agents stop and it's cut off from your account; nothing on it is deleted.

To wipe it, run this on the computer:

```sh
docker rm -f openhut openhut-updater && docker volume rm openhut openhut-data
```

This removes OpenHut and its agents' own files there. It can't be undone. What's in your account stays. Docker stays installed.
