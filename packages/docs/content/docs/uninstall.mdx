---
title: Uninstall
description: Remove Fast Monkey, its agents, its data and its firewall from your server.
icon: monkey
---

Run this as root:

```sh
sh /opt/fastmonkey/install/uninstall.sh
```

It asks you to type `uninstall`, then removes Fast Monkey, every agent, all its data, its firewall rules and the `fastmonkey` user. This can't be undone.

Docker, gVisor and Node stay installed.

No `uninstall.sh` there? Your install is older than the script. Run the install command once to upgrade, then run this.
