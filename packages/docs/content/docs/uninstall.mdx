---
title: Uninstall
description: Remove OpenHut, its agents, its data and its firewall from your server.
icon: hut
---

Run this as root:

```sh
sh /opt/openhut/install/uninstall.sh
```

It asks you to type `uninstall`, then removes OpenHut, every agent, all its data, its firewall rules and the `openhut` user. This can't be undone.

Docker, gVisor and Node stay installed.

No `uninstall.sh` there? Your install is older than the script. Run the install command once to upgrade, then run this.
