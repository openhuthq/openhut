---
title: Uninstall
description: Remove OpenHut, its agents and its data from your server.
icon: hut
---

```sh
docker rm -f openhut && docker volume rm openhut
```

This removes OpenHut, every agent and all its data. It can't be undone. Docker stays installed.

## Older installs

Installs from before 17 November 2026 run directly on the server, in `/opt/openhut`. Run this as root instead:

```sh
sh /opt/openhut/install/uninstall.sh
```

It asks you to type `uninstall`, then removes OpenHut, every agent, all its data, its firewall rules and the `openhut` user. Docker, gVisor and Node stay installed.

No `uninstall.sh` there? Your install is older than the script. Run the install command once to upgrade, then run this.
