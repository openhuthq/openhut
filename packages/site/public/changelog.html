0.1.2 November 18, 2026 GitHub ↗

See an update in the app

When a new version has downloaded, the app says so and offers Restart to update.

Polish

A new agent tells you its job in the chat, and the Connections, Models and MCP screens are tidier and denser. The installer also handles a container it has to move.

0.1.1 November 18, 2026 GitHub ↗

Calmer setup for a new computer

Adding a computer shows one word for what's happening and a small spinner, and says plainly what to do if it fails.

Fixes

On Linux the app says "this computer", not "this Mac". Agents keep working after the app moves or relaunches, the MCP command works without Node, a move interrupted by the network can't leave an agent running twice, and updates on the Mac install cleanly.

0.1.0 November 17, 2026 GitHub ↗

OpenHut is a Mac and Linux app

Download it, sign in to Claude and make your first agent. Each agent runs in its own sandbox on your computer, and one window shows them all.

Add an always-on computer

Add a Linux computer on your tailnet and agents keep answering while your Mac sleeps. Each computer runs its own Agent Runtime.

Move an agent to another computer

Pick another computer under Runs on. The agent moves with its memory and chats.

Set it up from your own AI

Settings › MCP has one command per computer for Claude Code, Codex, Cursor or Zed. Your AI can then make agents and grant access for you.

Runs on your Claude plan

Sign in with the Claude subscription you already pay for. On a Mac the sign-in is sealed in the Keychain.

Server preview November 15, 2026 GitHub ↗

Before the desktop app, OpenHut was a server you installed with one command and shared with your team. The app replaced it. Automations, webhooks, team sign-in and the People page belonged to that preview and are not in the app.

Watch your agents browse the web, live

Switch on Browser and an agent gets a real web browser inside its own sandbox. Take over to log in or get past a check.

Agents that work on their own

Give an agent an automation and it runs on a schedule, or when another app calls its webhook. It posts the result to Slack, Telegram or WhatsApp, and stays quiet when there's nothing new.

Your team's agents, on your own server

One command installs it. Each agent runs sealed in its own container, and you manage them all from one dashboard.

Chat in Slack, WhatsApp or Telegram

Each agent gets its own Slack app, WhatsApp number or Telegram bot. In Slack it answers in the channels you pick, private and shared ones included, so there are no member IDs to copy.

Agents see only what you allow

Connect a database once, then pick which agents can use it. They never see the password.

Set it up from Claude or Cursor

Paste one prompt into the AI assistant you already use. It connects to your server and builds agents with you.

Bring your whole team

Invite people as admins or members. Admins can change settings, members use the agents.

That's everything so far. Every commit is on GitHub.
