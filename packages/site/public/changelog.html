Changelog

The biggest things new in OpenHut, newest first.

OpenHut updates itself. New here? Install it.
Nov 27, 2026

Every thread in one place

Each conversation an agent has shows up in the web app, whether it started there, in Discord, from a webhook or from a routine. Open Threads at the top of the chat to find one, and archive the ones you're done with.

Nov 27, 2026

Live for everyone

Replies appear as the agent writes them, for everyone in the thread. You see who's here and who's typing, and a reply keeps going if you close the tab.

Nov 27, 2026

Alerts in their own thread

Related webhook calls, like an alert and its recovery, share one thread, and a resent call counts once. Each call shows as a card with its status and what happened.

Nov 27, 2026

A simpler agent page

The sidebar lists your agents, one per line. Setup holds everything about an agent, from its name and model to its routines and webhooks, and its browser shows in a small window you can move.

Nov 27, 2026

Agents answer in Discord channels

People can talk to an agent in the Discord channels you pick, private ones included. Its replies are saved in OpenHut first, so they show in the app too.

Nov 27, 2026

Updates keep chats going

Agents keep running through OpenHut updates and restarts, and a chat picks up where it left off.

Nov 26, 2026

Run OpenHut on your own server

One command installs it on a Linux server with Docker, HTTPS included, or behind a reverse proxy you already have. Your team signs in from the browser: copy an invite link from People and send it yourself.

Nov 26, 2026

Agents ask, you approve

An agent can ask to change its own name, instructions or channels, or for an app, a key or a webhook. A card shows up in the chat, and nothing changes until you approve it.

Nov 26, 2026

Changes without a restart

A new name, instructions, apps, keys or model reach an agent on its next turn, in the same chat. The few changes that need a restart wait until it's done working.

Nov 26, 2026

Choose what an agent may do in each app

Set each action to Always allow, Ask first or Never, per agent. When it asks first, you approve it from the chat.

Nov 26, 2026

GitHub without a token in the agent

Set up one GitHub App for your server, then pick the repositories each agent can reach. Its pushes go through OpenHut, which adds the key on the way, and each commit says which agent wrote it.

Nov 26, 2026

Webhooks and routines

Give an agent an address that other services call, like a DigitalOcean alert, and each call reaches it as a message. Agents also set up routines to follow up on their own. Find both in the agent's Setup.

Nov 26, 2026

Clearer replies

Agents answer first and keep it short by default. In the app, replies show tables, task lists and highlighted code with a Copy button, and every message gets an answer or a reason why not.

Nov 18, 20260.3.0

Run agents on Claude, Codex or an API key

Sign in with the Claude or ChatGPT plan you already pay for, or add a key from OpenRouter, OpenAI or xAI. Keys stay on your server, and agents never see them.

Nov 18, 20260.3.0

See what an agent remembers

Agents save notes about people and your business as they work. Open Memory to read, fix or remove any of them, and Skills to see what it has learned to do.

Nov 18, 20260.3.0

Give every agent its own face

Pick the colour, eyes, hair, a hat, glasses and a background, or hit Shuffle until one feels right.

Nov 18, 20260.3.0

Watch an agent browse the web, live

Switch on Browser and an agent gets a real web browser of its own. Watch it from the agent's page, and take over to log in or get past a check.

Nov 17, 20260.1.0

A new agent in one step

Pick a face, a name and a model, then tell it its job in the chat.

Nov 17, 20260.1.0

Add more computers

When your server runs out of room, add another Linux machine with one command. Move an agent between computers from Runs on, with its memory and chats.

Nov 15, 2026Preview

Talk to agents in Slack, WhatsApp, Telegram or Discord

Each agent gets its own Slack app, WhatsApp number, Telegram bot or Discord bot, and answers in the channels you pick.

Nov 15, 2026Preview

Connect a database or an app once, then pick which agents can use it. They never see the password.
