Where your agents live

On a server you own. A key safe on that computer holds your passwords and lets each agent use only the apps you allow. Each agent is sandboxed.

On your own server

Run one command on a Linux server with Docker and open the link it prints. Agents keep working while your laptop is shut.

On more machines

Add another computer from Settings with one command. Move any agent to it in one click.
